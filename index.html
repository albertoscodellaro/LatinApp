Condivisione

Per GitHub Pages

Il prototipo funziona senza server e può essere pubblicato come pagina statica. Tuttavia, modifiche salvate nel browser non si sincronizzano automaticamente con gli studenti: per distribuire una lista aggiornata, esporta il JSON e includilo nella nuova versione pubblicata.

Non inserire password segrete o dati personali degli studenti nel codice pubblico. Una password incorporata in una pagina statica non può essere tenuta segreta.
